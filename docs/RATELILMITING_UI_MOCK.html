Rate limiting

Per client IP: count the requests each address makes against this site over the window you name. When one address goes over the limit, it answers 429 until the window passes; the client IP is the one Cloudflare names in CF-Connecting-IP or the connecting address. Counters live in the panel process: a restart clears them.

Limit: 120 requests / 5 min Scope: /login, /cart/checkout only 7 addresses limited in the last hour

Counts reset with the window. The panel keeps at most one million (IP, path) keys so a flood of unique addresses cannot grow the memory past that bound.

What an over-the-limit client sees

HTTP/2 429
content-type: text/plain; charset=utf-8
retry-after: 12

Too many requests. Wait the window out and try again.

Only the over-the-limit address is refused; every other visitor is unaffected. The site's own health checks (the panel's probes, loopback) are never counted.
